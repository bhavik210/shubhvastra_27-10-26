SHUBHVASTRA NEW VERSION 2026 — WINDOWS SETUP

1. ZIP Extract All કરો.
2. Python 3 install કરો: https://www.python.org/downloads/windows/ (install વખતે Add Python to PATH પસંદ કરો).
3. જૂના software folderમાંથી party_reporting.db નો backup લો.
4. Existing party_reporting.db ફાઇલ app.pyની બાજુમાં મૂકો. ZIPમાં database નથી.
5. run_windows.bat પર double-click કરો.

નવી સુવિધાઓ:
- Party duplicate prevention: party name + phone + city + state ચારેય same હોય તો duplicate રોકાય છે.
- Editable Order Number; duplicate order number રોકાય છે.
- Save Order / Save PDF.
- Maximum 200 item rows.
- Find / Edit Order અને Delete Order.
- Dispatch history ધરાવતા orderનું edit/delete સુરક્ષા માટે રોકાય છે.

નોંધ: Python syntax check થયું છે. GUI/PDFનું સંપૂર્ણ end-to-end પરીક્ષણ તમારા કમ્પ્યુટર પર હજી કરવાનું બાકી છે. જૂની database overwrite ન કરશો.
