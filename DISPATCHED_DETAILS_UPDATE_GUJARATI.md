SHUBHVASTRA Update — Item Master Utilities માં અને Dispatched Details

1) Item Master હવે main navigation માં અલગ menu તરીકે નથી. તે Utilities dropdown માં મૂક્યું છે. Admin અને Member તેને જોઈ શકે છે; Staff માટે અગાઉની જેમ Item Master access નથી.

2) Main navigation માં Dispatched Details ઉમેર્યું છે. તેમાં:
   - Party Wise Dispatched History: Party પસંદ કરતાં તેની dispatched transaction history દેખાય છે.
   - Agent Wise Dispatched History: Agent પસંદ કરતાં તેની સાથે જોડાયેલી Parties ની dispatched history દેખાય છે. જરૂર પડે તો તે Agent ની એક Party પણ પસંદ કરી શકાય છે.
   - બંને views માં PDF Download વિકલ્પ છે.
   - History existing order_dispatches records પરથી બને છે; કોઈ dispatch record કે business data delete/replace કરાતો નથી.

Update પહેલાં live database નો backup રાખવો. આ ZIP માં live database સામેલ નથી અને તેને upload/replace કરવાની જરૂર નથી.
